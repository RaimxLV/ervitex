# NWG1907087 focused correction — preview only

## Evidence and root cause

Product: Craft **T&F Performance Custom Warm-up Pants Jr**.
Existing public regular retail rows: **82.50 EUR net / 99.83 EUR incl. VAT**, for exact SKUs
`1907087-000-110`, `-122`, `-134`, `-146`, `-158`; sizes 110/116–158/164.
All five current SKU availability values are zero; they remain selectable, unchanged.
The actual item is `1907087-000`, colour code `000`, with no supplier colour name.
Its exact item image is `https://images.nwgmedia.com/highres/343608/1907087-000.jpg`.
No colour name or HEX was invented, and orphan `Unicolor` was not copied.
`nwg_variants.raw` is null for both items; no linked manual product was found.

The materialized catalogue colour aggregate accepts only non-null colour label/hex.
It therefore drops the real unnamed `-000` item while retaining named `-0000` with no SKUs/image.
The model image and price range survive, but exact-colour card pricing correctly refuses the orphan.
An additional shared-matcher defect applied Malfini middle-digit candidates to hyphenated NWG IDs,
allowing two same-model distinct colours to appear equivalent. That inference is now restricted to non-hyphenated codes.
Numeric colour labels normalize to empty strings under canonName; NWG now avoids fuzzy/canonical name matching.

- `src/lib/nwgIdentity.ts`: common exact product/item-to-SKU join and catalogue construction from public variant identity columns. No stock/promotion/price computations. Bounded paginated reads only for currently visible models, in parallel; failed reads do not manufacture identity.
- `src/lib/nwgIdentity.test.ts`: real/orphan, cross-model, distinct zero codes, zero stock, positive price/VAT and zero-price rejection.
- `src/components/catalog/UnifiedCatalog.tsx`: batched visible-model identity overlay, including old IndexedDB records; no NWG model-range fallback when no actual colour exists.
- `src/components/services/TechRelatedProducts.tsx`: same upstream identity construction before reused cards; colours without HEX still retain exact price/image identity, without fake swatches.
- `src/components/catalog/CatalogItemDialog.tsx`: common exact join, same label, no fuzzy numeric name match; stale colour URLs recover to a real priced selection with visible notice. No-SKU items show unavailable and no add control or borrowed price.
- `src/lib/colorCodeMatch.ts`: NWG hyphenated codes never use MF middle digits.
- `src/hooks/useCatalogCardImages.ts`: NWG images compare whole item identities, not candidate suffixes.
- `AGENTS.md`, `roadmap.md`: decision and completion.

The database materialized view remains unchanged; application loaders reconstruct the actual colours on each visible-model read, so refresh/rebuild cannot reintroduce the orphan in these card paths. No DB repair is required for this preview solution.
All existing price formulas, retail records, stock data, manual exclusions, supplier publication gates and previous pending edits are unchanged.
